# Reference sources

`assets/catalog.json` records original file paths, SHA-256 hashes, source revision,
capture date and public example URLs from Comwit shop-studio. Screenshots are
unchanged copies of the maintainer-provided public gallery, captured on 2026-10-15.
They show storefront UI, not customer/order records or commercial performance.
Category groups organize observed examples, not product capability claims.

The source does not state a separate screenshot license. The maintainer requested
reuse here for references and docs; do not claim the product photography, logos or
brands are licensed assets for a generated shop. Use the user's own or separately
licensed assets in its pages. Preserve this provenance when copying references.
Do not fabricate screens or substitute generated images.

The docs generator copies this catalog and images from the pinned shop submodule.
Update this directory first; never maintain a second image catalog.

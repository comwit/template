# 디자인 시스템

## 기본 원칙

- **설명보다 구조로 전달합니다.** 버튼의 위치와 크기, 정렬, 선택 상태로 동작을 알립니다. 부연설명을 쌓지 않고 필요한 이름과 오류 안내는 분명히 씁니다.
- **카드에 모든 것을 넣지 않습니다.** 제목과 섹션 설명은 밖으로 빼고, 관련된 내용만 묶습니다. 구분은 여백부터 씁니다.
- **한 구역에는 하나의 메시지를 담습니다.** 제목 위의 작은 장식 문구와 반복 설명을 덜고, 중요한 내용은 충분히 크게 보여줍니다.
- **읽어야 할 내용은 선명하게 씁니다.** 본문과 주요 값은 또렷하게, 날짜와 힌트는 한 단계 낮게 표현합니다. 색상만으로 상태를 구분하지 않습니다.
- **같은 역할은 같은 모습으로 만듭니다.** 색상·글자·간격·컴포넌트를 일관되게 쓰고, 아이콘과 움직임은 의미가 있을 때만 더합니다.
